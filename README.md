---

Page de présentation de Salawat. Le code de l'application est dans un dépôt privé.

- `index.html` — la page, en un seul fichier, sans dépendance.
- `version.json` — version publiée, taille, lien de l'APK, empreinte SHA-256.
  Lu par la page, et par le mécanisme de mise à jour de l'application.
- `.nojekyll` — sert la page telle quelle, sans traitement Jekyll.

L'APK n'est pas dans les fichiers du dépôt : il est joint aux Releases, qui n'ont
aucune limite de bande passante, là où GitHub Pages en a une.
